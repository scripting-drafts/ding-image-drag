# ding-image-drag

Patched local build of Desktop Icons NG (DING) for Ubuntu 22.04 / GNOME 42.
Dragging an image from Firefox onto the desktop now downloads and saves the
image instead of ignoring the remote URL.

Install: `./install.sh` then restart the shell (Alt+F2, `r`, Enter).
Revert: `./revert.sh` then restart the shell.

Based on DING 2022-06-28 (ding@rastersoft.com), GPL-3.0. Patch: `patch/`.
